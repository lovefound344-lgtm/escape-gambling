이번 버전에서 변경된 핵심
1. 모바일 max-w-md 중심 구조를 16:9 전자칠판/태블릿 중심 반응형으로 개편
2. CASE FILE → 사건 브리핑 → 학급 등록 → 수사본부 흐름 추가
3. 수사본부 6개 메뉴(사건 기록/수사 미션/수집 단서/인물 조사/스마트폰/장소 조사) 추가
4. 기존 LocalStorage, 타이머, QR, 암호 입력, 단서 8개, 최종 추리 로직 보존
5. 저장 기록이 있으면 재접속 시 수사본부로 바로 복귀
6. 확정 스토리라인에 맞게 기존 임시 단서 문구를 HOT7/재연/동훈/준혁 설정으로 정리
7. 제공한 이미지 세트를 GitHub 친화적인 영문 파일명 폴더로 정리

테스트 방법
- 가장 간단: 이 폴더 전체를 GitHub 저장소 루트에 업로드 후 GitHub Pages 실행
- 로컬: 브라우저에서 index.html을 열 수 있으나 QR 카메라는 HTTPS 또는 localhost 환경이 더 안정적입니다.

다음 개발 단계
- 장소 조사: 배경 위 투명 단서 오브젝트 클릭/확대/증거 등록
- 인물 조사: 표정 변화가 있는 선택형 심문 대화
- 스마트폰: 메신저/SNS 인터랙티브 포렌식
- 미니게임: 웹 미션과 현장 미션 연결
- 최종 추리: 확정안의 복수 선택/재심문 재도전 구조 반영
